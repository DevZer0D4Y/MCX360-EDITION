# Your game files go here

Nothing from the game is distributed with this project. Copy in the files you
extracted from **your own** Minecraft: Xbox 360 Edition disc:

```
game/
├── default.xex      <- from the disc
├── default.xexp     <- from Title Update 9 (needed at build time for codegen)
├── res/
├── Tutorial/
└── ...everything else from the disc
```

Required: Title ID `584111F7`, Media ID `7CD33B56`, version `0.0.10.1` after TU9.
